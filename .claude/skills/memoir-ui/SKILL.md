# Memory Gallery 界面设计规范

> ⚠️ 本 skill 只服务于这一个项目,不要拿去别处套用。

## 一、设计命题(所有决定都从这里推导)

**把平凡的日子变得不平凡。**

用户传进来的是随手拍的截图、没什么故事的午餐、下班路上的天。产品的职责不是「把它们整齐地列出来」,而是**让人重新看见它们的分量**。

判断任何设计的唯一标准:

> 用户看到自己那些普通照片被这样呈现之后,会不会觉得**「原来我这几天过得还挺像回事的」**?

如果只是排得整齐、加载得快、点得到 —— 那是文件管理器,不是回忆录。

推论:
- **仪式感优先于信息密度**。宁可一屏少放几条,也要让每条有被郑重对待的样子。
- **具体优先于统计**。「已连载 3 话」不如「8月的第三个周末,青岛」。数字是给系统看的,场景是给人看的。
- **克制的隆重**。隆重不等于花哨 —— 是大留白、大字号、有分量的边框和硬投影,不是更多颜色和特效。

## 二、材质隐喻:会动起来的单行本

> ⚠️ **2026-08-28 修订**:原来这里写的是「印刷品不会自己动」。
> 周令杰明确推翻了这条 —— 他要动态。以下是修订后的口径,**别再拿旧规则说事**。

界面的**质感**仍然是印刷品:实色平涂、墨线、网点、硬投影、纸张纹理、烫色块。
但它**不是一张不动的纸,是一部动起来的漫画**。

两件事分开看:

**质感(不变)** —— 仍然禁用:渐变、毛玻璃、发光、柔和阴影、模糊。
这些不是"静止"的问题,是它们会毁掉印刷质感。看到 `bg-gradient-*`、
`backdrop-blur`、`shadow-lg` 依然是跑偏信号。

**动态(全面放开)** —— 元素可以持续动、可以自己动、可以有环境动效。
判据从「书会不会动」换成:

> **这个动作,让画面更像一部动起来的漫画,还是更像一个花哨的网页?**

动画番会做的,这里就能做:速度线扫过、集中线收束、拟声词弹跳与抖动、
纸面轻微起伏、格子依次亮起、镜头推近、角色出场的顿帧。
纯网页装饰(通用的粒子雨、无意义的 3D 倾斜卡片、彩虹渐变流光)仍然不做 ——
不是因为"纸不会动",是因为它们不属于漫画的语言。

## 三、令牌(唯一色源,定义在 globals.css)

```
--ink    #17130e   暖墨      文字、描边、硬投影
--paper  #fbf7ee   旧刊纸    所有底色
--accent #d6402b   印刷红    重点、CTA、当前态。整屏只用一两处
--sun    #f7c948   蜡黄      标签、强调块
--sky    #6db3d1   网点青    次要标签、冷静区
--on-bright #17130e 亮底墨字  压在黄底/青底上的文字与图标。两个主题都不翻转
```

暗色模式 = **夜刊**(炭纸白线),`--ink` 与 `--paper` 对调,不是简单反色。

**禁止**在组件里写字面色值,一律 `var(--ink)` 这样引用 —— 否则暗色模式必然某处翻车。

## 五、排版

- **标题** `font-black`(900),这是漫画标题的重量。半吊子的 600/700 会显得没底气。
- **正文** `font-bold`(700)。这个界面里没有 400 —— 印刷品的文字是有墨的。
- **数字**用 `tabular-nums`,尤其页码和计数。
- 中文正文标点**必须全角**(,。?!:「」),代码块与行内代码标签除外。半角逗号在中文界面里是机器输出的观感。
- 竖排标题用 `writing-mode: vertical-rl` + `text-orientation: upright`,字号随字数收放,别溢出。

## 六、主界面(dashboard)的特殊要求

主界面是用户每次进来第一眼看到的东西,**它决定这个产品在用户心里是「相册」还是「作品」**。

必须做到:

1. **开篇要有场面**。顶部不能是「你好,XX」加一排按钮。要有一个能立住的头图区:连载状态、最近一话的封面、或者一句从内容里提炼出来的话。
2. **具体地说事**。不要「3 本回忆集 · 12 张照片」,要「最近一话:8月28日,收了 5 张」。
3. **回忆集是书,不是卡片**。要有书脊、卷号、封面照压边这些「书」的特征。
4. **时间线是连载表,不是列表**。话数、日期、当话代表图,像单行本的目录页。
5. **空状态是第 0 话**,不是「暂无数据」。要让人想开始画第一话。

## 七、动效(2026-08-28 大改:要动态)

判据:**这个动作属于漫画的语言吗?**

### ✅ 该做的:动画番的语汇

**持续动效**(可以一直动,不必等交互):
- 速度线横向扫过 —— 冲击、加速
- 集中线呼吸式收束 —— 注意力汇聚
- 拟声词抖动、弹跳、放大缩小 —— 声音的视觉
- 网点纸面缓慢漂移 —— 印刷网点的活气
- 主角格轻微推近(ken burns 式,幅度极小)

**入场动效**:
- 格子依次亮起 / 落到纸上,带节奏差(不是同时淡入)
- 标题砸下,伴随冲击波与顿帧
- 从右侧入场,契合漫画右起动线

**交互动效**:
- 按钮按下位移、卡片抬起微旋
- 翻页的纸感转动
- 悬停时格子抬起、拟声词弹一下

### ⛔ 仍然不做:不属于漫画的网页装饰

- 通用粒子雨、星空、雪花
- 无意义的 3D 倾斜卡片
- 彩虹渐变流光、霓虹呼吸
- 视差滚动(多层相对滑动,是网页手法不是漫画手法)

理由不再是「纸不会动」,而是**它们不是漫画的语言**。

### 实现口径

- 滚动相关优先 CSS 原生 `animation-timeline: view()`,零 JS。
- 持续动效用 `@keyframes` + `animation: … infinite`,GPU 友好的属性
  (`transform` / `opacity` / `background-position`),别动 `width`/`top` 这类会重排的。
- **必须**用 `@media (prefers-reduced-motion: no-preference)` 包住所有动效 ——
  这是无障碍底线,不因为"要动态"就放弃。
- 幅度可以大,但要有理由:大开大合留给标题与关键一击,正文区域保持克制。
- 同屏持续动效不超过 3 处,否则整页都在动 = 什么都没强调。

## 八、文案语气

作者对读者说话,不是系统对用户播报。

| 别写 | 要写 |
|---|---|
| 上传成功 | 咔嚓!收下了 |
| 暂无数据 | 故事还没开始 |
| 生成展览 | 装订成册 |
| 3 个项目 | 全 3 话 |
| 操作失败 | 这一步没成,再试一次 |

⛔ 不要出现:策展、展览、展品、数字生活、社交内容。这些是上一版产品的残留。

## 九、自检(交付前逐条过)

```
□ 有没有渐变 / 毛玻璃 / 发光 / 柔和阴影?  → 有就是跑偏了
□ 有没有写死的十六进制色值?              → 应该全用 var()
□ 暗色模式下每个新元素都验过吗?
□ 中文正文标点是全角吗?
□ 这一屏能不能一眼看出「这是一本书」?
□ 用户看到自己的普通照片被这样排,会不会觉得挺像回事?
□ 320px 宽度下有没有横向滚动?
```

最后一条是这个 skill 存在的理由。前面所有规范,都是为了让最后一条成立。
